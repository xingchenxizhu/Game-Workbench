# 大地图拼接

入口：世界场景 → 大地图拼接，路由 `/#/tool/stitch`。旧 MapStitch 项目仍可从页面中的旧版入口打开；新工具不迁移浏览器中原有 IndexedDB 工程。

## 使用流程

1. 导入首张图片，建立地图单格尺寸。
2. 设置俯视、45° 等距或横版视角，以及横纵重叠比例。
3. 用方向按钮或虚线格选择相邻位置，再导入图片或创建扩图任务。
4. 保存地图工程后，再关闭页面或切换工作区。
5. 按需求导出整图、分层 PSD、完整状态包或引擎地图包。

不同尺寸的后续图片会提示并规整到单格尺寸。鼠标右键/中键平移、滚轮缩放；本地编辑支持撤销。读取、导入或新建地图前请保存修改。

## 扩图与图层

横纵重叠分别支持 0–45%，按像素取整。扩图任务携带邻边参考和空白蒙版。开启 [ChatGPT 自动生图](ChatGPT生图.md) 后，新任务可自动生成、回填到对应格并继续队列；关闭时需通过任务中心手动交接和回填。

扩图队列最多创建 16 块、同时等待 1/2/4 块；底层生图执行器仍有自己的并发限制。停止队列只停止后续创建，已建任务保留。中断或取消的关联任务需要检查后重试，不会伪装为成功结果。

支持整体、地表、透明物件和预览层。黑白物件蒙版由物件层 alpha 生成，不是从整图进行自动语义分割。重叠图片按空间顺序覆盖，不保证自动消除接缝或保持道路连续。

## 保存与导出

地图工程按当前工作区保存；完整状态 ZIP 和本工作台导出的引擎包包含 `map-state.json`，可以恢复图片、坐标、图层及任务关联。不支持任意第三方引擎工程的导入。

- PNG：当前预览层整图，或每块按 1/4/9 份切分。
- PSD：栅格图层和合成预览。
- Godot 4：地图场景、Sprite2D、相机、PNG 和 `project.godot`。
- Unity：PNG 与 `WorkbenchMapLoader.cs`，需合入 Unity 工程并配置相机；不是可执行游戏。

地图包不自动提供角色、碰撞或导航。文件导出成功不等于已在引擎中运行。

## 容量与验证

最多 64 个地图层块、6400 万像素；整图导出最多 3200 万像素、单边 16384；PSD 合成最多 1600 万像素。超限时改用分块导出。

`npm run check:stitch` 在隔离工作区验证参考图、蒙版、队列回填、状态恢复、工作区约束和下载文件；模型风格连续性及 Godot/Unity 实际运行仍需另外验证。
