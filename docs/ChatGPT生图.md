# ChatGPT 自动生图与回填

适用于浏览器网页和 DSH 插件。安装与功能入口见 [README](../README.md)。

## 使用

1. 本机安装 Codex 并登录 ChatGPT。后台检查账号类型为 chatgpt、提供方支持内置生图，不使用 API Key 替代。
2. 设置 → 生成后端 → 切换为 ChatGPT 技能。图片、角色、骨骼和原素材引擎的图片请求会进入同一任务桥。
3. 设置 → 行为与数据 → 开启“ChatGPT 生图：创建任务后自动生成并回填”，保存。今后新建的生图任务自动派发；不会自动重跑旧任务。
4. 在原功能填写想制作的素材或使用模板。工作台自动组装提示词、透明背景要求和参考图，调用内置图片工具；不需要再手动复制指令或挑选生成文件。
5. 成品按原任务 ID 回填。原素材模块的等待请求继续执行，流程页、素材包、地图扩图和任务中心通过原有订阅显示结果；保存到当前工作区素材目录。

任务中心可单张重试、启动待回填队列或停止。取消/停止不会删除提示词、已生成图片或旧项目。自动生图消耗当前 ChatGPT 账号用量，额度或模型不支持时显示实际失败原因，不自动改用付费 API、代码绘图或占位图。

工作台不会替用户猜测空白素材需求。“自动填写”指将功能表单和参考图转换为完整生图请求；用户仍需指定要制作什么。音乐和视频等独立服务不属于图片生成技能。

## 技能

项目技能：`.agents/skills/game-workbench-imagegen/SKILL.md`。后台会显式传入该技能；交互聊天也可按技能处理任务。技能已通过 skill-creator 的 quick_validate。

运行通道依据 [OpenAI 官方 App Server 文档](https://learn.chatgpt.com/docs/app-server) 和本机 Codex 生成的协议类型实现：初始化、能力/账号检查、独立临时线程、turn/start、imageGeneration 完成项、turn/completed。没有通过电脑操作向当前聊天注入消息，也不读取账号令牌或密码。

## 相比旧实现的修复

- 删除时间戳扫描全局 generated_images 的结果猜测；只接受匹配 threadId/turnId 的结构化生图文件，防止多聊天、多任务串图。
- 正确传入实际参考图路径和透明背景，不再只传文字。工作台显示工具实际尺寸，不伪称精确像素尺寸。
- 使用正常 workspace-write 沙箱；后台不自动批准额外权限请求，遇到需审批步骤会失败并提示在交互聊天处理。
- 去重、串行队列、32 项上限、每项超时、失败信息、取消和终态锁；生成期间阻止工作区切换，素材保存位置在任务开始时固定。
- 完成/取消/阶段更新顺序化，避免取消后状态又被旧阶段覆盖；服务重启明确标为中断。
- 保留每张图片的 auto-receipt.json，记录原任务、会话、轮次和图像项 ID。

## 验证方法与边界

- `npm test`：任务与配置等回归检查。
- `npm run check:auto-image`：隔离环境下使用固定运行器验证自动派发、回填和结果显示，不调用真实模型。
- `npm run check:image-live`：显式调用真实图片工具，会消耗账号用量，不属于普通离线测试。

结果写入本地 `test-results/`，不会随源码提交。历史验证记录不代表当前机器已经配置好账号或额度，也不等于在真实 DSH 中安装验收通过。

需要本机 Codex、ChatGPT 登录、图片额度和网络。图片质量、角色与地图一致性仍需人工检查，失败任务会保留以便排查和重试。
